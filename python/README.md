# Splat3D quickstart: Python

Needs Python 3.10+. Standard library only: nothing to install.

```bash
export SPLAT3D_API_KEY="s3d_..."
python3 quickstart.py capture.mp4                  # --preset fast --format spz --out .
python3 quickstart.py --scene-id a1b2c3d4e5f6      # resume a scene
```

See [../README.md](../README.md) for options, exit codes and errors.
